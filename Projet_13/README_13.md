# Projet BottleNeck - Rapprochement et Analyse des Données de Ventes

Notebook d'analyse des ventes (ERP + Web) pour BottleNeck, amélioré grâce à l'IA
de manière critique et documentée (Module 13).

## Contenu
- `Notebook_ameliore.ipynb` : notebook Python (nettoyage, fusion, détection
  d'outliers, analyse CA/marge/stock, corrélations)
- `Module_13_OC_DOCUMENTATION.docx` : documentation complète (veille
  technologique, cahier des charges fonctionnel, gestion de projet, glossaire)

## Installation
```
pip install -r requirements.txt
jupyter notebook Notebook_ameliore.ipynb
```
